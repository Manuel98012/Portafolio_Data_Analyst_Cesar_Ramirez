Segmentación de clientes

Python · Scikit-learn · Pandas · Seaborn

Objetivo

Agrupar clientes según sus hábitos de compra para orientar estrategias de marketing personalizadas por segmento.

Herramientas usadas

Python Scikit-learn Pandas Seaborn

Proceso / metodología

  • Cálculo de variables RFM (Recencia, Frecuencia, Monto) por cliente.
  • Normalización de variables y reducción de outliers.
  • Aplicación de clustering con K-Means y selección del número óptimo de grupos.
  • Interpretación y perfilado de cada segmento resultante.

Resultados clave

  • Se identificaron 4 segmentos de clientes con comportamientos de compra claramente diferenciados.
  • El segmento de mayor valor representa una minoría de clientes pero una gran parte de los ingresos.
  • Se propusieron acciones de marketing específicas para cada segmento (retención, reactivación, fidelización).
